🛠️ Methodology

A reproducible analytical chain, from raw data to decision.

  1. Understanding & cleaning — missing values, duplicates, types, outliers (IQR), accounting-identity checks.
  2. Engineered features — margin rate, cost ratio, discount rate, ROI.
  3. SQL analysis — KPIs, top products, country/segment performance, monthly growth (window functions).
  4. Simplified income statement — Gross Sales → Discounts → Net Sales → COGS → Net Profit.
  5. Forecasting — moving average / linear regression / SARIMA comparison (MAE, RMSE).
  6. Power BI dashboard — KPIs, trends, map, margins, forecasts + interactive filters.
